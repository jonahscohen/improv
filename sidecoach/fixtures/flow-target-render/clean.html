Build Pipeline Notes

The build pipeline reads each source file once and writes a single output bundle. Configuration lives in one file at the project root. Every command prints what it changed and returns a distinct exit code for each class of failure, so a script can branch on the result without parsing text. Logs are written to standard error and the report to standard output. When a step cannot complete it stops and explains which input it could not read, rather than continuing with a partial result.
