Verge Foundry draws text faces for long reading

Six families, each drawn from a single set of skeletons so a text weight and a display weight sit together without a size-specific optical mismatch.

Optical sizes

Every family ships text, deck, and display opticals rather than one drawing scaled up. The text cut carries open counters and a taller x-height for small sizes; the display cut tightens spacing and sharpens the joins where a large size can carry the detail.

Licensing

Desktop licences are perpetual and seat-counted. Web licences are priced on monthly pageviews with no expiry, and an app licence covers unlimited installs of one named product. We do not charge for a rebrand and we do not audit your traffic.

Trials

Full trial families are available for any comping work, watermark-free, with the same character set as the retail release. The only restriction is that trials may not ship in a published product.
