Ferrule API

Ferrule exposes a single REST surface for creating, listing, and cancelling shipments. Every endpoint takes and returns JSON, and every response carries the request id in a header so a support ticket can be traced without you pasting a payload.

Authentication

Send your key as a bearer token. Keys are scoped to one environment and can be rotated without downtime: the old key stays valid for one hour after a rotation, and both keys appear in the audit log so you can confirm the cutover completed before the window closes.

curl -H "Authorization: Bearer $KEY" https://api.example.test/v1/shipments

Rate limits

Limits are per key and per endpoint family. A request that exceeds the limit is rejected with a retry-after header rather than queued, so a runaway loop fails fast instead of building a backlog you cannot see. The published numbers are floors, not targets.

Versioning

The version lives in the path. A version stays supported for eighteen months after its successor ships, and breaking changes never land inside a version. Additive fields can appear at any time, so parse defensively and ignore what you do not recognize.
