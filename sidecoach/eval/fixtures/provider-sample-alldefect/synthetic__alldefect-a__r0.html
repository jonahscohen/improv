All-defect fixture A

A heading that skips from level one to level three

This paragraph is deliberately set with justified text alignment so that the shipping objective scanner detects a WCAG 1.4.8 justified block. It contains more than one sentence and well over one hundred and twenty characters of placeholder body copy. The uneven inter-word spacing that justification produces is exactly the defect this class exists to catch.

A second justified paragraph reinforces the planted defect. It, too, runs several sentences and carries enough placeholder text to clear the block-of-text threshold. Justified body copy on the web produces rivers of whitespace and harms readability for many people, which is why the rule flags it.

This fine print placeholder copy is set far below a comfortable reading size. It repeats enough small text to cross the tiny-text proportion floor so that the tiny-text class also fires on this fixture page. Small legal-style text like this strains readers and is a common real defect.
