The long and deliberately tightly set release heading

The first build shipped to the pilot team on a Tuesday, and by Friday they had filed nineteen reports, most of them about the export dialog losing the last folder a user had picked.

A second heading, also set with tight display leading on purpose

The second build fixed the folder memory and added a keyboard shortcut for the export, which the pilot team had asked for twice in the notes attached to their earlier reports.

The third build was mostly cleanup, trimming the startup time and removing a settings panel that nobody in the pilot group had opened once across the whole four weeks of testing.
