**Codex v4 fix - ABANDONED shell-parsing, went robust-by-construction:** the open-discharge arm now requires the ENTIRE trimmed command to match `^(open|xdg-open|start)\b(flags)*\s+<path>\s*$` (re.match, trailing `$`). The command must be NOTHING BUT a lone open of one file. This closes the whole bypass class: any prefix (echo/printf/cd &&) or suffix (`; rm`, `&& echo`) breaks the anchors, and there is no shell text that is entirely `open <path>` yet does not open it, so a FALSE discharge is impossible by construction. Removed the shlex import. Cost: a chained `cd .. && open X` no longer auto-discharges - the SAFE direction (artifact stays flagged; run `open <path>` alone to show it). This is the lesson: matching an opener inside arbitrary shell is an endless quoting rabbit hole; requiring the whole command to BE the open sidesteps it.
