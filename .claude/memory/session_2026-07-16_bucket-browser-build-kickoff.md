SELF-RESOLVED (coordinator, on closer analysis - NOT a real blocker, no escalation needed): `install.sh --only <comp>` ALWAYS installs the component's scaffolding (CLAUDE.md section, startup-check, daemon/skill build) regardless of the hook off-list; the off-list only controls which HOOKS get wired.
