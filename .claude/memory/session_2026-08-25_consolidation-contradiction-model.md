CURRENT STATE (answered): the ingested pioneer docs are UNTRUSTED DATA the miner reads, NOT live rules. Overlap is resolved REACTIVELY at mine time - a distilled candidate is deduped against the live registry (strong-identity => duplicate dropped; weak-resemblance => flagged; novel => net-new). DECISION - THE RECONCILIATION MODEL (Jonah's, build to it exactly): contradictions are NOT one thing. Classify every distilled rule by TYPE and classify each contradiction by the types involved:
- HARD-PROHIBITIVE (absolute ban/mandate, "never font X, use Y"): two opposing => a REAL conflict, must resolve (flag prominently).
- DESIGN-DIRECTION (brutalist vs editorial vs minimalist vs soft - the intended MENU we always keep): NOT a conflict; surface as a direction PAIR, both kept, never asked to reconcile. Grounded in the sources self-labeling directions (Leon ships brutalist/minimalist/soft as separate skills; oracle ships bolder.md + quieter.md as context-conditional docs).
- STANDARD/MEASUREMENT (border-radius px, spacing units, type-scale ratios): can genuinely disagree between designers => a CALIBRATION conflict; flag with the values, Jonah picks one or a range.
- (PRINCIPLE/GUIDANCE: soft advice.)
RULING: "flag EVERY contradiction while being discerning" - do NOT auto-scope or auto-tiebreak silently (rejected my earlier direction-scope-first-with-oracle-tiebreak proposal); surface all contradictions but CLASSIFIED by type so Jonah is never handed a flat pile. Direction-pairs shown as the menu (not conflicts); hard-prohibitive + standard conflicts foregrounded for his call.

BUILD: a CONSOLIDATION + CONTRADICTION MAP - an upfront survey over the whole ingested corpus + our live registry that clusters distilled rules by concept, tags each by type, shows covered/additive/redundant vs our live rules, and flags every contradiction classified by the above types with a recommendation each. It is a REPORT / inert data - nothing auto-applies to the live layer; it feeds Jonah's review + the existing human-gated promote/enforce path. The distillation core (telling a hard ban from a direction from a measurement out of prose) is a reflect/mine-style FLOW + a deterministic engine (typed schema, cluster/contradiction model, report renderer, --check), reusing the miner's corpus assembly.
