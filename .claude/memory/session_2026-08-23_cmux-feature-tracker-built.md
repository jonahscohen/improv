# cmux feature-tracker built (Phase 2 of the learning-researcher framework)

Collaborator: Jonah. Built as an executor teammate against HEAD bddbea14 on the now-committed shared spine
(scheduled-research-run.sh + the plist template + the taste-miner inert-quarantine pattern). PROPOSE-ONLY
and HUMAN-GATED per the design beat and the framework's FULLY-GATED apply decision: it discovers and
proposes; it never modifies the harness or bumps the cmux pin. Built in parallel with the sibling CC-tracker
teammate (both touched hook-registry-guard.sh; the two launchd-wrapper exemptions coexist cleanly).

## What was built (7 files, 1 exemption edit)

- **`claude/cmux/cmux-tracker.py`** (~755 lines, self-contained python3 stdlib, fail-loud exit codes). The
  deterministic engine + LOCAL-introspection source adapter. Subcommands:
  - `snapshot [--out]` - the current cmux SIGNAL (cli_version+build+hash from `cmux version`, sorted
    capabilities+methods+access_mode+protocol+protocol_version from `cmux capabilities`). Volatile fields
    (socket_path, per-launch) are EXCLUDED so an unchanged cmux compares equal across runs.
  - `precheck --cursor` - the SRR run/skip gate. resolve cmux (absent -> skip) -> VERSION-ONLY -> pin gate
    (below pin -> skip, decided on version alone) -> full signal -> compare to cursor (equal -> skip, changed
    or first-run -> run). Prints run|skip as the LAST stdout line, exit 0 on a decision; a RESOLVABLE-but-
    not-introspectable cmux (broken/format-drifted) exits 2 (fail loud) so the SRR runner never reads a
    broken gate as a forever-skip.
  - `diff --cursor` - the capability set-diff (cursor vs live): added/removed capabilities+methods, version
    delta, first_run. The COMPREHEND-step input the model flow consumes.
  - `advance --cursor` - writes the current live snapshot into the cursor (the SRR_ADVANCE_CMD write-back).
  - `propose --spec` - renders ONE inert proposal markdown from a structured spec into the quarantine, with
    path containment + filename sanitization + a fenced untrusted-excerpt block.
  - `verify-inert` - asserts no harness/enforcer file (claude/hooks, sidecoach/src|scripts|bin,
    settings.json, install.sh) sources the quarantine; exit 0 inert, 1 not.
- **`claude/hooks/cmux-tracker-daily.sh`** - the thin SRR wrapper: exports SRR_JOB_NAME / cursor+log under
  $HOME/.claude / PRECHECK (cmux-tracker.py precheck) / PROMPT (a directive pointing at the flow doc) /
  SUCCESS (a fresh dated queue beat) / ADVANCE (cmux-tracker.py advance), then execs the shared runner.
- **`claude/launchd/com.yesand.cmux-tracker-daily.plist`** - instantiated from the shared template, daily at
  04:00 (staggered off reflect Sun-09:00 and the CC-tracker 03:00). NOT installed into launchd (user's step).
- **`claude/cmux/cmux-track-flow.md`** - the `/cmux-track` flow doc the headless `claude -p` follows:
  untrusted-data posture up front, diff -> WebFetch changelog (UNTRUSTED DATA, gh not installed) -> comprehend
  to typed records -> opportunity-map against the 8 cmux touch-points (weighted to workaround-RETIREMENT) ->
  propose + ALWAYS write a dated queue beat.
- **`claude/proposals/cmux-tracker/`** - the INERT quarantine: `README.md` (inertness doc) + `_EXAMPLE.md`
  (a real-format sample generated by the tool, reproducible byte-identical; the read_state-retires-close-guard
  case). Git-tracked, sourced by nothing.
- **`claude/hooks/hook-registry-guard.sh`** - added a launchd-exemption for `cmux-tracker-daily` (same class
  as beats-reflect-weekly: launchd-scheduled, no settings.json event, nothing to wire or toggle).
- **`claude/cmux/test-cmux-tracker.sh`** - a 33-assertion hermetic contract test (a fake-cmux stub drives
  every version/capabilities scenario, so it passes on a cmux-less machine).

## Key decisions

**Python3 tool under claude/cmux/, NOT a sidecoach node bin.** The deterministic engine is a self-contained
python3 stdlib tool (repo convention for hook/cmux tools; beside cmux-preflight.sh), so it needs NO
`generate-tool-index` DESCRIPTIONS entry and does not touch the sidecoach `npm run build`. The lead's
"register any new bin in the tool-index generator" clause is therefore N/A - no sidecoach bin was added.

**Single canonical cursor (`~/.claude/cmux-tracker/last-seen.json`), compared on a STABLE signal only.** The
SRR runner snapshots/rolls-back ONE cursor file; storing both signals in one JSON lets its cursor-integrity
guarantee protect the whole thing atomically. socket_path and other volatile fields are excluded from the
compared `signal`, so an unchanged cmux is a no-op skip (proven).

**DEFERRED: the SessionStart nudge/backstop.** The design (section 5) and the lead's spec both mention "a
SessionStart diff backstop if the design calls for it." I deliberately did NOT build it, because both of its
stated rationales are already covered: (1) launchd's built-in missed-fire-on-wake catch-up already reruns a
job whose time passed while the laptop slept (documented in the plist template), and (2) the beats-loading
protocol already surfaces the dated `proposal_cmux-features_*.md` queue beat at session start. An every-
session event hook adds real cost + noise + heavy test-assertion coupling (the component-browser suite
hardcodes the cmux component's hook list, counts, and desc-count), which does not earn its keep for a rarely-
firing propose-only researcher - and the framework's own anti-pattern warning is against adding surface that
nothing meaningfully invokes. Flagged to the lead as a bounded follow-up with the exact wiring recipe
(browser-tree hook_owner/hook_desc + cmux hooks list, app-wirings SessionStart entry, install.sh cmux
install_app_hooks + deactivate_cmux, and the component-browser cmux assertions). If the lead wants it, it is
a clean add.

## Safety (verified, non-negotiable)

- **Structural inertness proven**: `verify-inert` (exit 0) + a manual grep -> NO harness/enforcer file sources
  `claude/proposals/cmux-tracker`. The only referencer is the wrapper's own directive string (a WRITE target,
  excluded by the writer-basename allowlist, exactly as the taste miner excluded its own bin). Negative
  control: a planted enforcer reference is caught (exit 1).
- **Untrusted external data**: the flow doc leads with the posture; the tool renders changelog excerpts ONLY
  inside a DYNAMIC-length fenced `untrusted` block (a fence longer than any backtick run, so an embedded ```
  cannot break out). No fetched field is ever executed. cmux release notes are DATA, never instructions.
- **Containment**: a proposal that lands inside the repo MUST resolve under the LITERAL
  `claude/proposals/cmux-tracker/` prefix (realpath'd target's repo-relative path vs a literal prefix, so a
  symlinked quarantine cannot redirect it); out-of-repo scratch (/tmp, ~/.claude cursor) allowed; in-repo
  non-quarantine REFUSED (exit 4). Filenames are sanitized (no `../` escape via slug/version).
- **No write path into the harness**: the tracker writes ONLY the cursor (under ~/.claude) + inert proposals +
  the queue beat. It never edits a hook, settings.json, a skill, or cmux.version, and never auto-bumps the pin.

## Verification (proven, not claimed)

- **Pre-check contract** (the headline proof): first-run (no cursor) -> run; advance writes the cursor; an
  unchanged cmux -> skip; a mutated cursor (dropped capability) -> run; a socket_path-only change -> STILL
  skip (volatile isolation); cmux absent -> skip; below-pin (even with broken capabilities) -> skip;
  resolvable-but-broken/drifted cmux ABOVE pin -> exit 2 (fail loud). All through the FULL wrapper via
  `DRY_RUN=1` (skip prints nothing; run prints the exact claude invocation), with NO cursor written and NO
  claude invoked in DRY_RUN.
- **A sample proposal lands inert**: `propose` from a fixture writes `<version>-<slug>.md` into the
  quarantine; a hostile slug (`../../../../evil`) is sanitized and stays in-dir; a symlinked-quarantine and an
  in-repo-non-quarantine target are refused (exit 4); the untrusted excerpt is fenced.
- **Contract test**: 33/33 (`claude/cmux/test-cmux-tracker.sh`).
- **Integration gates GREEN**: hook-registry 94/0, component-browser 147/0, `npm run build` rc 0,
  hook-registry `--audit` + `--audit-data` clean.
- **Wiring**: `bash -n` clean (wrapper, test, guard); `plutil -lint` clean (plist); DRY_RUN-safe.
