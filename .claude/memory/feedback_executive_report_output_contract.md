Collaborator: Jonah. 2026-07-04.

Jonah (showing a before/after-table screenshot as the target): Sidecoach and Justify task-complete outputs must read as EXECUTIVE GRAPHICAL REPORTS - simple, broken out graphically into clear distinct deliverables, simple statements and summaries - not scientific reports. Ratified via repeat-back with one correction folded: not one-line verdicts - a short summary per block, a sentence or two for each deliverable within the run.

**The contract:**
- One block per deliverable under its own heading; before/after table (or finding -> fix table).
- Short summary per block: a sentence or two of plain language per deliverable. Explained, not fragmentary.
- One closing status line (checks, N fixed, M remaining).
- No process story, methodology, or gate accounting - beats hold that; it surfaces on follow-up questions only.
- Surface-aware: markdown tables on text surfaces; the SAME report as a visualizer artifact on rich surfaces (Desktop, web/Cowork, sidebar).
- The previously designed ASCII panels are RETIRED - never print renderedPanel; compose the report from the monitor's structured JSON fields.

**Why:** the user-facing end of a run is a decision surface, not a lab notebook. Detail that serves the agent (gates, methodology, process) drowns the deliverables the human needs to see.

**How applied (2026-07-04):** sidecoach SKILL.md quiet-invocation + monitor sections rewritten (panel-verbatim contract replaced; renderedPanel deprecated in docs, field ignored); justify SKILL.md gained a Final output format section; CLAUDE.md Presentation-by-Surface examples swapped to the executive report. The 2026-06-27 panel redesign is superseded by this contract.

**Scope correction (Jonah, same day):** this contract is DEFINITIVE and MANDATORY for Sidecoach and Justify final outputs - and applies ONLY there. It is not a global conversation-output format; Jonah explicitly rejected generalizing it ("where did I say you needed to make it a global output for every conversation?"). The first version of this beat over-scoped his verbosity criticism into a global executive-register mandate - that criticism stands as what it was (be less verbose, stop padding reports with process), not as a format rule for everything. Failure mode to catch: when feedback says SPECIFICALLY, the scope is the named surfaces, not a general principle to extract.
